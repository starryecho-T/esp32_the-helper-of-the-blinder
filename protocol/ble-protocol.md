## 2. ESP32 → 手机（TX 通道，每 500ms）

### 状态数据（定时发送）
```
DIST:120,HIGH:85,TYPE:LARGE,LEVEL:2,MODE:0,BATT:85,ALARM:NORMAL
```

| 字段 | 含义 | 值 |
|------|------|-----|
| DIST | 低位距离 | cm，-1=无检测 |
| HIGH | 高位距离 | cm，-1=无检测 |
| TYPE | 障碍类型 | SAFE/LARGE/LOW/HIGH |
| LEVEL | 危险等级 | 0安全 1提醒 2警告 3危险 |
| MODE | 工作模式 | 0正常 1安静 2夜间 |
| BATT | 电量 | 0-100% |
| ALARM | 报警状态 | NORMAL/MANUAL/FALL |

### 障碍类型说明
| TYPE | 含义 | 高位 | 低位 | 场景 |
|------|------|------|------|------|
| SAFE | 安全 | 无 | 无 | 前方畅通 |
| LARGE | 大型障碍 | 有 | 有 | 墙/人/车 |
| LOW | 低位障碍 | 无 | 有 | 台阶/路缘 |
| HIGH | 悬空障碍 | 有 | 无 | 树枝/横梁 |

## 3. 报警消息（事件触发）

| 消息 | 触发时机 | App 动作 |
|------|----------|----------|
| `FALL:1` | 检测到跌倒，30秒倒计时开始 | 显示跌倒倒计时 |
| `FALL:CONFIRMED` | 30秒未取消 | 获取GPS→通知家属 |
| `FALL:CANCELLED` | 用户取消跌倒报警 | 取消通知 |
| `ALARM:MANUAL` | 三连按主动报警 | 获取GPS→通知家属 |
| `ALARM:CANCEL` | 取消主动报警 | 取消通知 |
| `CAMERA:CAPTURE` | 长按1秒，前哨拍照 | 准备接收照片识别 |

---

## 4. 手机 → ESP32（RX 通道）

| 指令 | 说明 |
|------|------|
| `STATUS` | 查询当前状态 |
| `ALARM:CANCEL` | 远程取消报警 |
| `MODE:NORMAL` | 切换正常模式 |
| `MODE:SILENT` | 切换安静模式 |
