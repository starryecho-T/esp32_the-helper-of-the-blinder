## 1. 连接参数

| 项目 | 值 |
|------|-----|
| 蓝牙名称 | `ESP32_BLE_2026` |
| 蓝牙类型 | BLE 5.0（低功耗蓝牙） |
| Service UUID | `6E400001-B5A3-F393-E0A9-E50E24DCCA9E` |
| TX 通道 UUID | `6E400003-B5A3-F393-E0A9-E50E24DCCA9E` |
| RX 通道 UUID | `6E400002-B5A3-F393-E0A9-E50E24DCCA9E` |
| TX 属性 | NOTIFY（ESP32 主动推送，手机需订阅） |
| RX 属性 | WRITE（手机发送指令） |
| 配对密码 | 无（开放连接） |

---

## 2. 数据格式总则

- 所有通信使用 **纯文本 ASCII 字符串**
- 格式：`类型:值`（英文冒号分隔）
- 一条消息只包含一个数据项
- 不传输中文（BLE 对中文支持不稳定）

---

## 3. ESP32 → 手机（TX 通道，Notify）

手机需要**订阅 TX 通道的 Notify** 才能收到数据。

### 3.1 心跳数据

每隔 2 秒自动发送，App 可用来判断设备是否在线：

```
HEARTBEAT
```

### 3.2 障碍物距离

```
DIST:120
```
- 单位：厘米（cm）
- 示例：`DIST:120` = 前方 120cm 有障碍物
- 无障碍物时发送 `DIST:0` 或 `DIST:999`

### 3.3 跌倒报警

```
FALL:1
```
- `FALL:1` = 检测到跌倒，正在等待用户确认
- `FALL:0` = 用户已取消报警
- `FALL:CONFIRMED` = 用户未取消，已确认报警，请立即发送求助通知

### 3.4 电池电量

```
BATT:85
```
- 单位：百分比（%）
- 范围：0-100

### 3.5 当前工作模式

```
MODE:0
```
- `0` = 日常出行模式
- `1` = 夜间模式
- `2` = 安静模式
- `3` = 导航模式
- `4` = 紧急模式

### 3.6 GPS 位置

```
GPS:39.9842,116.3074
```
- 格式：`纬度,经度`（逗号分隔，6位小数）
- GPS 信号弱时发送 `GPS:NO_SIGNAL`

### 3.7 设备状态

```
STATUS:CONNECTED
```
- `STATUS:CONNECTED` = 前哨已连接
- `STATUS:SCOUT_LOST` = 前哨断开

---

## 4. 手机 → ESP32（RX 通道，Write）

App 通过写入 RX 通道来控制盲杖。

### 4.1 切换模式

```
MODE:0
```
- 值与 3.5 相同

### 4.2 主动查询

```
QUERY:DIST
QUERY:BATT
QUERY:GPS
```
- ESP32 收到后立即回复一次对应数据

### 4.3 取消报警

```
CANCEL_ALARM
```
- 家属端远程取消报警（可选功能）

---

## 5. App 端实现要点

1. **连接后第一件事**：订阅 TX 通道的 Notify，否则收不到任何数据
2. **心跳检测**：如果 5 秒内未收到 `HEARTBEAT`，判定设备离线
3. **DIST 解析**：收到 `DIST:120` 时，按冒号分割，取后半转为数字
4. **FALL 处理**：收到 `FALL:CONFIRMED` 时，立即获取当前位置并通知预设联系人
