## 一、系统概述

智能盲杖系统由三部分组成，协同实现"环境感知 → 危险判断 → 多维反馈 → 主动求助"的安全闭环：

| 设备 | 主控 | 职责 |
|------|------|------|
| **盲杖** | ESP32-S3 | 低位测距、跌倒检测、多模式反馈、BLE 通信 App、GPS 定位 |
| **前哨**（头戴） | ESP32-S3-CAM | 高位测距、图像采集、WiFi 拍照服务器 |
| **手机 App** | — | 状态显示、报警推送、远程控制、拍照查看 |

### 通信架构

```
手机 App
  │  BLE（盲杖↔App）
  │  WiFi HTTP（前哨↔App，拉取照片）
  ▼
盲杖 ESP32-S3  ←── ESP-NOW ──→  前哨 ESP32-S3-CAM
```

## 三、核心功能演示

### 3.1 障碍物检测与多维反馈（核心功能）

**原理**：盲杖底部超声波测低位障碍，前哨头戴超声波测高位障碍，融合判断障碍类型。

| 障碍类型 | 判定条件 | 蜂鸣器 | 振动 |
|---------|---------|--------|------|
| 低位障碍（台阶） | 低位有、高位无 | 低频 800Hz | 弱-强 |
| 高位障碍（树枝） | 低位无、高位有 | 高频 2500Hz | 弱-强 |
| 大型障碍（墙/人） | 低位有、高位有 | 交替 800/2500Hz | 弱-强 |
| 安全 | 都无 | 静音 | 无 |

**危险等级**（振动强度+蜂鸣节奏）：
| 等级 | 距离 | 振动 | 蜂鸣节奏 |
|------|------|------|---------|
| 1（远） | 80-150cm | 弱 | 每 900ms |
| 2（中） | 30-80cm | 中 | 每 400ms |
| 3（近） | <30cm | 强 | 每 120ms |

**演示方法**：
1. 正常模式，对着墙走
2. 逐渐靠近，蜂鸣器越来越急促、振动越来越强
3. 串口可见：`[测距] 低=85 高=120 类型=LARGE 等级=1 ...`
4. 只挡低位（手放盲杖超声波前）→ `类型=LOW 蜂鸣=低频800Hz`
5. 只挡高位（手放前哨超声波前）→ `类型=HIGH 蜂鸣=高频2500Hz`

### 3.2 跌倒检测与主动报警

**跌倒检测原理**（基于有限状态机）：
```
状态0（空闲）→ accMag<0.4g（失重）→ 状态1（疑似跌倒）
状态1 → accMag>2.5g（撞击）→ 状态2（确认跌倒）→ 30秒倒计时
状态1 → 2秒内无撞击 → 回到状态0（误判）
```

**30秒倒计时流程**：
1. 跌倒确认 → 振动强振 + 语音"您似乎跌倒了，三十秒后自动报警，拨动旋钮取消"
2. 每秒振动短促提示倒计时
3. 30秒内旋转旋钮/按键 → 取消报警，BLE 发 `FALL:CANCELLED`
4. 30秒到无人取消 → BLE 发 `FALL:CONFIRMED`，App 触发家属报警

**演示方法**：
- 串口输入 `fall` → 模拟跌倒，观察完整 30 秒倒计时流程
- 倒计时期间旋转旋钮 → 取消报警
- 或再次 `fall` 触发，不取消，等 30 秒看 `FALL:CONFIRMED`

**主动报警**：
- 快按编码器旋钮 3 次（相邻两次间隔不超过 0.8 秒）→ 进入主动报警 → BLE 发 `ALARM:MANUAL`
- 再快按 3 次 → 取消 → BLE 发 `ALARM:CANCEL`（串口打印 `[三连按] 取消报警`）

### 3.3 三种工作模式

旋转编码器半圈切换模式（每圈20脉冲，10脉冲≈半圈）：

| 模式 | 蜂鸣器 | 振动 | 语音 |
|------|--------|------|------|
| 正常 | 障碍响 | 障碍振 | 模式切换播报 |
| 安静 | 不响 | 障碍振 | 仅模式/跌倒/报警 |
| 夜间 | 障碍响 | 障碍振 | 模式切换播报 |

**演示方法**：旋转编码器半圈 → 语音播报模式名 + 串口打印 `[模式] 切换: 安静`，App 收到 `MODE:SILENT`

### 3.4 拍照功能

1. **长按编码器旋钮（按压 SW）超过 1.5 秒** → 串口打印 `[长按] 拍照！通知前哨`
2. 盲杖 BLE 发 `CAMERA:CAPTURE` 给 App
3. 盲杖 ESP-NOW 发拍照命令给前哨
4. 前哨摄像头预热
5. 手机浏览器访问 `http://<前哨IP>/capture` 拉取照片（前哨 IP 见其串口启动日志）

**演示方法**：串口输入 `photo` → 触发拍照流程

### 3.5 GPS 定位

- 盲杖 GPS 模块持续接收卫星数据
- BLE 周期上报（500ms）包含 `LAT:纬度,LNG:经度`
- 跌倒报警时附带位置信息

**演示方法**：串口输入 `gps` → 打印当前经纬度和卫星数

### 3.6 交通灯识别播报

App 端识别交通灯后经 BLE 上报（`RED`/`YELLOW`/`GREEN`/`NONE`），灯色**变化时**播报一次：

| 识别结果 | 语音 |
|---------|------|
| 红灯 | "红灯，请等待" |
| 黄灯 | "黄灯，请注意" |
| 绿灯 | "绿灯，可以通行" |

**演示方法**（二选一）：
- 串口依次输入 `light RED` → `light GREEN`（无需真实识别，展示播报效果）
- App 端发送识别结果（需要队友 App 配合）

**创新点话术**：视障者过马路无法看到远处信号灯，由前哨摄像头 + App 图像识别判断灯色，通过语音引导通行时机，补足超声波"只能测距不能识物"的盲区。

## 五、BLE 通信协议（App 对接）

### 5.1 盲杖 → App（Notify）

**周期上报（每500ms）**：
```
DIST:85,HIGH:120,TYPE:LARGE,LEVEL:1,MODE:0,BATT:85,ALARM:NORMAL,
FALLST:0,ENC:42,ACC:1.02,MPU:1,LAT:30.123456,LNG:120.654321,LIGHT:无
```

**事件消息**：
| 事件 | 消息 |
|------|------|
| 旋转切模式 | `MODE:NORMAL` / `MODE:SILENT` / `MODE:NIGHT` |
| 长按拍照 | `CAMERA:CAPTURE` |
| 三连按报警→开 | `ALARM:MANUAL` |
| 三连按报警→关 | `ALARM:CANCEL` |
| 跌倒触发 | `FALL:1`（每3秒重发） |
| 跌倒取消 | `FALL:CANCELLED` |
| 跌倒30秒到 | `FALL:CONFIRMED` |

### 5.2 App → 盲杖（Write）

| 指令 | 效果 |
|------|------|
| `MODE:0` | 切正常模式 |
| `MODE:1` | 切安静模式 |
| `MODE:2` | 切夜间模式 |
| `ALARM:CANCEL` | 取消所有报警 |
| `CAMERA:CAPTURE` | 触发拍照 |
| `RED` / `YELLOW` / `GREEN` / `NONE` | 交通灯识别结果，变化时语音播报（红灯请等待/黄灯请注意/绿灯可以通行） |

## 八、常见问题排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 开机卡 `boot:0x23 DOWNLOAD` | GPIO0 被拉低 | 拔掉 GPIO0 上的接线 |
| 超声波一直 -1 | 接线/跳线帽/5V | 拔跳线帽、确认5V、Trig/Echo不接反 |
| 蜂鸣器太响 | 占空比太大 | `vol` 命令或改 `ledcWrite(BUZZER_PIN, 40)` |
| App 连不上蓝牙 | BLE未广播/距离远 | `status` 看 BLE 状态，靠近重试 |
| 前哨照片拉不到 | WiFi没连上 | 确认前哨和手机在同一热点 |
| ESP-NOW peer channel 报错 | 信道不一致 | 两板连同一热点，代码自动同步信道 |
| 跌倒不触发 | MPU掉线 | `status` 看 MPU=在线，检查 SDA/SCL 接线 |
