## 一、引脚分配总览

| GPIO | 连接模块 | 功能 |
|------|----------|------|
| GPIO 4 | 振动马达 IN | PWM 振动强度控制 |
| GPIO 5 | 超声波 TX(Trig) | 触发测距 |
| GPIO 14 | GPS TX → ESP32 RX | 接收 GPS NMEA 数据 |
| GPIO 15 | GPS RX ← ESP32 TX | 发送给 GPS（一般不用） |
| GPIO 16 | TTS TX → ESP32 RX | 接收 TTS 返回（可选） |
| GPIO 17 | ESP32 TX → TTS RX | 发送文本给 TTS |
| GPIO 18 | 超声波 RX(Echo) | 接收回波 |
| GPIO 20 | MPU6050 SCL | I2C 时钟线 |
| GPIO 21 | MPU6050 SDA | I2C 数据线 |

> 注意：GPIO 0 不能接任何模块，否则 ESP32-S3 会卡在下载模式。

## 二、各模块接线详情

### 1. 超声波模块（US-100）

| US-100 引脚 | ESP32-S3 | 说明 |
|-------------|----------|------|
| VCC | 5V | 必须接 5V |
| GND | GND | |
| TX (Trig) | GPIO 5 | 触发脉冲 |
| RX (Echo) | GPIO 18 | 回波读取 |
| EN | 不接 | 悬空 = GPIO 模式 |

> ⚠️ US-100 背面跳线帽必须**拔掉**，否则是 UART 模式，代码不兼容。

---

### 2. 振动马达模块（KE2071）

| 马达引脚 | ESP32-S3 | 说明 |
|----------|----------|------|
| VCC | 5V | |
| GND | GND | |
| IN | GPIO 4 | PWM 控制振动强度（0-255） |

---

### 3. MPU6050 姿态传感器（GY-521）

| GY-521 引脚 | ESP32-S3 | 说明 |
|-------------|----------|------|
| VCC | 3.3V | ⚠️ 不能接 5V |
| GND | GND | |
| SDA | GPIO 21 | I2C 数据 |
| SCL | GPIO 20 | I2C 时钟 |
| AD0 | 不接 | 悬空，地址 0x68 |
| INT | 不接 | |
| XCL | 不接 | |
| XDA | 不接 | |

> I2C 地址：0x68

---

### 4. TTS 语音合成模块（HS-S77-PL）

| TTS 引脚 | ESP32-S3 | 说明 |
|----------|----------|------|
| G | GND | |
| V | 5V | 功放需要 5V |
| RX | GPIO 17 | ESP32 → TTS，发送文本 |
| TX | GPIO 16 | TTS → ESP32，接收返回（可选不接） |

> - 串口波特率：115200（不行试 9600）
> - 编码：GBK（Arduino 源码是 UTF-8，中文需预编码）
> - ⚠️ 需要外接喇叭，模块上有喇叭接口（SPK）
> - 帧协议：`0xFD 0x00 长度+2 0x01 0x05` + GBK 文本

---

### 5. GPS 定位模块（HS-S78P）

| GPS 引脚 | ESP32-S3 | 说明 |
|----------|----------|------|
| G | GND | |
| V | 5V | GPS 功耗较大，接 5V |
| T (TX) | GPIO 14 | GPS → ESP32，NMEA 数据 |
| R (RX) | GPIO 15 | ESP32 → GPS（一般不用） |

> - 串口波特率：9600
> - 需要安装 TinyGPSPlus 库
> - ⚠️ 必须接天线！否则报 `ANTENNA OPEN`
> - 首次定位需 1-3 分钟，放窗户边或室外

## 三、供电说明

| 电源 | 电压 | 给谁 |
|------|------|------|
| 5V | 5V | 超声波、振动马达、TTS、GPS |
| 3.3V | 3.3V | MPU6050（⚠️ 不能接 5V） |

> ESP32-S3 开发板的 5V 引脚来自 USB 供电，3.3V 来自板载稳压。
> 如果电流不够（GPS+TTS+马达同时工作），建议外接 5V 电源。

## 四、通信方式汇总

| 通信方式 | 引脚 | 模块 |
|----------|------|------|
| GPIO 数字 IO | 5, 18 | 超声波 |
| PWM (LEDC) | 4 | 振动马达 |
| I2C | 20 (SCL), 21 (SDA) | MPU6050 |
| UART (Serial1) | 14 (RX), 15 (TX) | GPS |
| UART (Serial2) | 16 (RX), 17 (TX) | TTS |
| BLE | 内置 | 手机 App |
