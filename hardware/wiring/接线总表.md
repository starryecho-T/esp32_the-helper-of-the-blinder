## 一、盲杖主控引脚分配

| GPIO | 模块 | 接口 | 说明 |
|------|------|------|------|
| GPIO0 | — | — | ⚠️ BOOT 引脚，勿用（开机需为高，否则进下载模式） |
| GPIO1 | 电池分压 | ADC1 | 电量检测 |
| GPIO3 | SYN6288 TX | UART2 RX | TTS 返回（不接也行）⚠️ 此脚为 strapping，仅作输入只读 |
| GPIO4 | 振动马达 | PWM | 振动强度 |
| GPIO5 | 超声波 Trig | GPIO | 触发测距 |
| GPIO6 | 编码器 A | 中断 | 旋转检测 |
| GPIO7 | 编码器 B | 中断 | 旋转检测 |
| GPIO8 | 编码器 C（按钮） | GPIO轮询 | 三连按报警/长按拍照（原 GPIO0，避让 BOOT） |
| GPIO9 | MPU6050 SCL | I2C | 时钟线（原 GPIO20，避让 USB_D+） |
| GPIO10 | MPU6050 SDA | I2C | 数据线（原 GPIO21，与 SCL 一并挪到安全脚） |
| GPIO14 | SYN6288 RX | UART2 TX | ESP32→TTS 发文字 |
| GPIO18 | 超声波 Echo | GPIO | 回波读取 |
| GPIO15 | GPS TX | UART1 RX | 接收 NMEA 定位数据 |
| GPIO16 | GPS RX | UART1 TX | 发指令给 GPS（一般不用） |
| GPIO17 | WS2811 灯带 | RMT | 夜间模式警示灯 |
| GPIO19/20 | USB_D-/D+ | — | ⚠️ 本板被 CH340X 占用，勿作他用（含 I2C） |

> ⚠️ GPIO0 是 BOOT 引脚，启动瞬间必须为高电平，绝不能接会拉低的器件（原按钮在此导致开机进下载模式）。  
> ⚠️ GPIO19/20 是 USB 引脚，本开发板 Micro USB 经 CH340X 隔离，非直连，这两个脚不能作 I2C/JTAG。MPU6050 原 SCL(GPIO20) 已改到 GPIO9。  
> ⚠️ GPS 原 `gps_test.ino` 用 GPIO14，与 SYN6288 TTS 冲突，集成时已改到 GPIO15/16。

## 二、盲杖各模块接线

### 1. 超声波模块（US-100）
| US-100 | ESP32-S3 |
|--------|----------|
| VCC | 5V |
| GND | GND |
| TX(Trig) | GPIO5 |
| RX(Echo) | GPIO18 |
| EN | 不接 |

> 背面跳线帽拔掉 = GPIO 模式

### 2. 振动马达（KE2071）
| 马达 | ESP32-S3 |
|------|----------|
| VCC | 5V |
| GND | GND |
| IN | GPIO4 |

### 3. MPU6050（GY-521）
| GY-521 | ESP32-S3 |
|--------|----------|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO10 |
| SCL | GPIO9 |
| AD0/INT/XCL/XDA | 不接 |

> ⚠️ 原 SCL 用 GPIO20，但 GPIO20 是 USB_D+，本板被 CH340X 占用，不能做 I2C，已改到 GPIO9。

### 4. 旋转编码器（EC11，5脚带按钮）
| EC11 引脚 | ESP32-S3 | 说明 |
|-----------|----------|------|
| A | GPIO6 | 旋转相A（中断） |
| B | GPIO7 | 旋转相B（中断） |
| SW | GPIO8 | 按钮（按下与GND导通，中断） |
| GND | GND | 旋转和按钮公共地 |
| VCC | 3.3V | 编码器供电 |

> ⚠️ 原按钮接 GPIO0（BOOT 引脚），开机若被拉低会进下载模式，已改到 GPIO8。
> 旋转：每圈20脉冲，转10脉冲（约半圈）切换一个模式。
> 按钮（轮询消抖，串口实时打印点击计数）：长按≥1.5秒=拍照（有振动确认），三连按（相邻间隔<0.8秒）=报警/取消报警。

### 5. SYN6288 语音合成
| SYN6288 | ESP32-S3 |
|---------|----------|
| VCC | 5V |
| GND | GND |
| RX | GPIO14 |
| TX | GPIO3 |
| 喇叭 | 模块喇叭口 |

### 7. 电量检测
| 分压电路 | ESP32-S3 |
|----------|----------|
| 电池+ → 分压 → | GPIO1 |
| GND | GND |

### 8. WS2811 灯带（夜间警示）【暂不演示】
| WS2811 | ESP32-S3 | 说明 |
|--------|----------|------|
| DIN | GPIO17 | 数据线（RMT 驱动） |
| VCC | 12V 独立电源 | ⚠️ 实测供电不足时不亮，演示前需解决供电 |
| GND | GND | **必须与板子共地** |

> 代码功能已实现且保留：夜间模式常亮警示（安全=暖白光，中近=橙色，极近/跌倒/报警=红色急促闪烁）；
> 正常模式=绿色呼吸灯；安静模式=关闭。演示视频暂不拍此模块，供电解决后可直接启用。

### 9. GPS 定位（HS-S78P / ATGM336H）
| GPS 模块 | ESP32-S3 | 说明 |
|----------|----------|------|
| V (VCC) | 5V | 模块可 5V 供电 |
| G (GND) | GND | |
| T (TX) | GPIO15 | GPS→ESP32，NMEA 数据（Serial1 RX） |
| R (RX) | GPIO16 | ESP32→GPS，一般不接 |

> 模块上电后持续输出 NMEA 语句，用 TinyGPS++ 解析。  
> ⚠️ 原 `gps_test.ino` 接的是 GPIO14，与 TTS 冲突；集成进 main 前需把 `GPS_RX_PIN` 改成 15、`GPS_TX_PIN` 改成 16。

## 四、两板通信

| 方向 | 数据 | 方式 |
|------|------|------|
| 前哨→盲杖 | 高位距离+等级 | ESP-NOW |
| 盲杖→前哨 | 拍照命令 | ESP-NOW |
| 盲杖→手机 | 状态数据 | BLE |
| 前哨→手机 | 摄像头照片 | WiFi HTTP |

### MAC 地址
- 盲杖 S3: `94:A9:90:CA:AE:64`
- 前哨 CAM: `28:84:85:4B:AB:BC`

## 七、串口调试命令（盲杖主固件）

串口波特率 115200。开机自动横幅 + 模块自检。演示/调试时输入以下命令，回车执行：

| 命令 | 作用 |
|------|------|
| `help` / `?` | 显示全部命令 |
| `status` | 打印完整状态（距离/模式/电量/姿态/GPS/连接） |
| `selftest` | 重新自检全部模块 |
| `tts` | 测试语音播报（依次播报） |
| `vol <0-16>` | 语音音量 |
| `buzzer` | 蜂鸣器扫频测试 |
| `motor <0-255>` | 设置振动马达强度（`motor` 单独用=关闭） |
| `mpu` | 打印当前加速度 |
| `gps` | 打印 GPS 经纬度与卫星数 |
| `dist` | 打印当前低位/高位距离 |
| `btn` | 打印按钮电平/状态（排查按钮接线） |
| `btnflip` | 翻转按钮极性 |
| `led` | 灯带测试（红→绿→蓝→白各1秒，灯带未接时无现象） |
| `mode <0-2>` | 切换模式：0=正常 1=安静 2=夜间 |
| `light <RED/GREEN/YELLOW/NONE>` | 模拟交通灯识别结果（演示用） |
| `fall` | **模拟跌倒**，触发 30 秒倒计时全流程（演示用） |
| `alarm` | 切换主动报警 |
| `photo` | 拍照（通知前哨预热 + 通知手机拉取） |
| `pause` / `resume` | 暂停 / 恢复自动测距与反馈（暂停后可单独调外设） |

> 串口持续打印 `[测距]` 行（500ms 一条，含低/高位距离、类型、等级），按钮点击实时打印计数，跌倒状态变化时打印。
